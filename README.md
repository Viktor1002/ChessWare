# ChessWare 1.9.2 — Firefox / Tampermonkey

## Лоадер з GitHub

[Встановити ChessWare Loader](https://raw.githubusercontent.com/Viktor1002/ChessWare/main/ChessWare.loader.user.js)

1. Відкрийте посилання у Firefox із встановленим Tampermonkey та натисніть Install. Якщо раніше встановили повний ChessWare, вимкніть його, залишивши увімкненим лише Loader.
2. Відкрийте Chess.com. Лоадер підключиться до цього репозиторію, завантажить актуальний захищений скрипт і перевірить розмір та SHA-256 із `release.json`.
3. Натисніть **Load**. Другий скрипт виконається в поточній вкладці з дозволами Tampermonkey; встановлювати його окремо не потрібно. **Insert** відкриває меню ChessWare. Усі функції в новому конфігу вимкнені; режими та автоходи вмикаються вручну.

**Exit** ховає вікно лоадера. До запуску ChessWare його можна повернути клавішею Insert, після запуску — командою **Show / hide ChessWare Loader** у Tampermonkey. Після повного перезавантаження вкладки натисніть Load знову. При переходах усередині сайту вже запущена копія не дублюється. Помилки мережі показуються у Status, кнопка Retry повторює підключення. Файл із невірним хешем не виконується.

Макет основного вікна відтворено за наданим Gamesense.pub loader: рамка 520 × 400, текстура, спектральна лінія, список продуктів, Options та Status, компактна Verdana. Назва продукту — ChessWare; повідомлення відображають реальний стан завантаження. Паролі, вигадана авторизація та терміни ліцензії не використовуються.

Локальна папка, Node.js, окрема програма чи локальний сервер на іншому комп’ютері не потрібні. Tampermonkey зберігає встановлений лоадер у профілі браузера, а отриманий код ChessWare живе в пам’яті поточної сторінки. Конфіги залишаються у localStorage цього браузера. Для роботи потрібен доступ до GitHub; це не офлайн-варіант.

Код лоадера: `loader/`; збірка: `npm ci`, `npm run build:protected`; перевірка двоетапного запуску: `npm run test:loader`. Вихідний код відповідної версії, ресурси, залежності та інструкції збірки доступні в `source/ChessWare-1.9.2-source.zip` під GPL-3.0-or-later. Обфускація не робить код секретним і не гарантує відсутності блокувань Fair Play.

Userscript для активных партий Chess.com: **мультиплеер, боты, Live Chess и Daily Chess**. Полная Stockfish 19 NNUE работает локально в Web Worker. Ограничение только бот-режимом удалено. Иконка ножа удалена из меню.

## Запуск на другом компьютере

Нужен только **один файл `dist/ChessWare.user.js`**, Firefox с Tampermonkey и доступ к интернету. Вставьте весь код в новый userscript и сохраните. Папка проекта, Node.js, локальный сервер, отдельная программа или ручная установка движка не нужны. Иконки и шрифты уже встроены в скрипт; полный Stockfish загружается автоматически при включении анализа и проверяется по SHA-256. Это сетевой userscript, не офлайн-сборка. Конфиги хранятся отдельно в каждом браузере. Все функции изначально выключены; открыть меню — Insert.

## Установка или обновление

Обфусцированный вариант — `dist/ChessWare.protected.user.js`. Он также устанавливается одним файлом в существующий скрипт ChessWare; отдельная программа не нужна. Обычный `dist/ChessWare.user.js` остаётся доступен. Выберите один вариант для установки.

Сборка усложняет чтение собственного JavaScript: переименовывает идентификаторы, кодирует строки RC4, перестраивает часть переходов и добавляет ложные ветви. Шрифты, CSS, иконки, chess.js и файлы Stockfish не обфусцируются; метаданные Tampermonkey и проверка SHA-256 движка сохранены. Нет sourcemap и зависимости от сервиса обфускации при запуске. Сборка локальная, исходники не отправляются внешнему сервису. Алгоритм сборки: `scripts/build-protected.mjs`, отчёт/хеши: `dist/ChessWare.protection.json`.

Это усложнение исходника клиентской программы, а не невосстановимое шифрование: браузер всё равно исполняет код. Защита не обещает обход Fair Play. Принудительная блокировка DevTools и поломка после форматирования не включены, чтобы сохранить работоспособность Tampermonkey. Опции инструмента описаны в [официальной документации javascript-obfuscator](https://github.com/javascript-obfuscator/javascript-obfuscator).

1. В Firefox откройте редактор вашего скрипта в Tampermonkey.
2. Замените **весь** код содержимым `dist/ChessWare.user.js` и сохраните `Ctrl+S`.
3. Перезагрузите страницу Chess.com. В Tampermonkey должна быть включена одна копия ChessWare.
4. Откройте свою партию. Доска и цвет определяются автоматически; тип противника не ограничивается.

Начальный конфиг пустой: **все переключатели выключены**, включая визуалы, чамсы, вотермарку и автоопределение игры. Меню открывается клавишей **Insert**. При обновлении до 1.8.1 текущие переключатели и базовый Default сбрасываются один раз; именованные сохранённые конфиги сохраняются. После этого ваши настройки визуалов сохраняются как обычно.

Для анализа сначала включите **Misc → Auto-detect Game Mode**, затем **Enable Legit** или **Enable Rage** и нужные функции режима, например Continuous Analysis. Автоходы включаются отдельно. Поддержка людей и ботов сохранена.

Включённые режимы и автоходы не записываются в конфиги и не восстанавливаются после перезагрузки. Загрузка конфига выключает их, сохраняя глубину, силу, задержку и остальные параметры. При обнаружении другой партии, смены доски или своего цвета, отката истории либо выхода из игры анализ и очередь ходов отменяются; для новой партии нужен ручной запуск. Обычные ходы в той же партии режим не выключают.

Эти изменения предотвращают непреднамеренный запуск и перенос помощи между партиями. Снижение числа срабатываний Fair Play не измерялось; гарантии отсутствия блокировки нет.

Первое включение загружает около **95 MiB / 99 MB** полной WASM-сборки с GitHub Releases. Прогресс показывается в меню. Версия закреплена, SHA-256 проверяется. Упрощённый движок или Lite вместо полной NNUE не подставляется. Уже загруженные данные повторно используются в текущей вкладке.

## Управление

| Действие | По умолчанию |
|---|---|
| Открыть / скрыть меню | Insert |
| Остановить анализ, автоходы и очередь хода | F8 |
| Перемещение старого меню | Верхняя полоса рамки |
| Перемещение нового меню | Заголовок |

| Открыть скрытое меню | Щелчок по вотермарке или команда Tampermonkey |

В Misc меняется только клавиша открытия меню. **Rage → Engine → Stop All Assistance** содержит настройку клавиши глобальной остановки; сама кнопка остановки находится в Rage → Search. Клавиша остановки работает и при фокусе в поле, на слайдере или чекбоксе. Ручной Analyse Position, его бинд и кнопки запуска полностью удалены. После ручного включения режима настройка Continuous Analysis разрешает анализ следующих позиций в этой партии; Auto Play / Auto Move дополнительно разрешают автоходы.

Меню изначально скрыто. Откройте его клавишей **Insert**, щелчком по вотермарке или командой Tampermonkey. Открытое/закрытое состояние сохраняется отдельно для текущей вкладки через `sessionStorage`: переходы по Chess.com и перезагрузка страницы не раскрывают скрытое меню. Загрузка конфигов и смена оформления также не открывают его.

## Вотермарка

**Misc → General → Watermark**, при необходимости прокрутите эту панель.

Формат: `название_темы | ваш_ник_Chess.com | ping | время`. Для темы chessence используется `chessence`, для NeverChess — `NC`, для Fatachessty — `Fatachessty`. Вариант NeverChess сохраняет NC и компактное синее оформление. Вотермарка Fatachessty использует фон/рамку меню, исходный Josefin Sans Bold, прописное название с RGB-смещением. Animation включает одинаковую с меню анимацию; reduced motion отключает её.

- Бренд определяется оформлением. Поля Watermark Brand и Nickname удалены.
- Ник определяется из данных текущего аккаунта и собственной ссылки профиля в навигации Chess.com, в том числе вне партии. При недоступном контексте Firefox работает чтение из DOM. Дополнительный источник — подтверждённая сторона игрока через `getPlayingAs`, без привязки к развороту доски. Профиль соперника и произвольные ссылки на участников не выбираются. Пока профиль не определён, отображается `…`.
- Аватар берётся из данных аккаунта или изображения собственного профиля на странице. Если URL ещё нет, используется публичный профиль [Chess.com PubAPI](https://support.chess.com/en/articles/9650547-what-is-the-pubapi-and-how-do-i-use-it). Запрос без cookies, результат кэшируется в памяти; позиции и ходы в этот запрос не входят. При смене аккаунта устаревший запрос отменяется. При отсутствии изображения/ошибке загрузки показываются инициалы. Картинка из исходника меню больше не используется.
- Ping — измеренное время HTTP HEAD-запроса к `/favicon.ico`, обновляется раз в 30 секунд в активной вкладке. Это HTTP RTT. При ошибке — `— ms`.
- Ping, Time и секунды включаются отдельно. Тикрейт и его настройки удалены, в том числе из старых конфигов при загрузке.
- Формат часов 12/24 часа, локальное время браузера.
- Четыре угла, отступы X/Y, прозрачность.
- Настройки отображения сохраняются в конфиге. Ник обновляется с сайта и не записывается в пресет вручную.

## Шахматные функции

- **Legit:** те же основные группы, что в Rage: Enable, Best Move, Auto Play, Continuous Analysis, Search Depth, MultiPV, Move Time, Evaluation, Best Line, Mate Detection, Threat Analysis. Отличие — настоящий ограничитель Stockfish **Skill Level 0–10 из 20**, по умолчанию **4**. Поиск ограничен глубиной 16, временем 2500 мс, одним потоком и Hash до 64 MB. Move Delay задаёт задержку автохода. Старые настройки искусственных ошибок и стилей заменены реальным ослаблением движка.
- **Rage:** полная Stockfish 19 NNUE через Stockfish.js 19.0.1, Best Move, Auto Play, Continuous Analysis, Depth, MultiPV, Move Time, Threads, Hash, оценка, PV, мат и атакованные фигуры. Оценка приводится с точки зрения белых. Поиск ограничен глубиной и временем; Continuous Analysis запускает поиск после смены позиции.
- **Threat Analysis:** атакованные фигуры стороны, которой принадлежит ход, с пометкой незащищённых. Это геометрия атак, а не отдельный поиск всех форсированных угроз.
- **Visuals:** последний ход, выбранная фигура, легальные ходы, взятия, одна/несколько стрелок, атакованные фигуры, шах и мат, цвета, толщина, прозрачность. Градиентные подсветки и аккуратные стрелки с лёгкой тенью плавно появляются и исчезают за 220 мс. Повторное включение во время исчезновения продолжает анимацию без пересоздания элемента. Animation и системная настройка reduced motion отключают переходы. При смене FEN, доски или стороны старая разметка удаляется сразу, чтобы не показывать ход от другой позиции.
- **Visuals → Piece Chams:** окраска силуэтов своих и чужих фигур, фигуры лучшего хода, цели взятия, выбранной фигуры и атакованных фигур. У каждой группы собственный переключатель и цвет; Chams Opacity и Chams Glow управляют прозрачностью и свечением. На Chess.com используются маски изображений текущего набора фигур. Цель берётся из проверенного легального хода движка; при взятии на проходе отмечается именно исчезающая пешка. При выключении роли возвращается обычный цвет своей/чужой фигуры; Enable Piece Chams выключает все чамсы. Animation управляет плавным появлением и исчезновением. Подсветка не перехватывает клики.
- **Материалы чамсов:** Flat, Glow, Outline, Wireframe, Glass, Metallic, Neon, Scanline. В NeverChess откройте **Visuals → Chams**, правую панель Chams Materials. В Skeet эти настройки находятся внутри Piece Chams. Material задаёт общий материал; Own / Opponent / Move / Target / Selected / Threat Material позволяют выбрать отдельный, а Inherit следует общему. Extra Outline, Outline Width и Pulse работают отдельно. Scanline плавно прокручивает полосы при включённой Animation. В редакторе цвета прозрачность каждой группы независимая и умножается на общую Chams Opacity. Контуры строятся по реальному силуэту фигуры.
- **Misc:** масштаб и размеры, расположение, оформление, клавиши, вотермарка, звук изменения позиции, автоматическое обнаружение игры.
- **Configs:** Create, Save, Load, Delete, Rename, до 50 пресетов в `localStorage`. Звёздочка в footer означает отличие текущих настроек от сохранённого пресета.

Legit и Rage взаимоисключающие. При смене позиции, конфигурации или выходе со страницы игры старые результаты и отложенные ходы отменяются. Автоход выполняется только на своём ходу и проверяется по текущей FEN и списку легальных ходов. У наблюдателя нет управляемого цвета — автоходы не выполняются. Анализ рассчитан на обычные шахматы; нестандартные правила не выдаются за поддерживаемые.

В Legit используется итоговый UCI `bestmove`, выбранный самим ослабленным Stockfish. Он может отличаться от первой строки MultiPV и даже отсутствовать среди видимых кандидатов. Выбранная строка помечается; если полной линии для неё нет, показывается только ход с `—` вместо выдуманной оценки. White eval относится к позиции, а не автоматически к выбранному слабому ходу. При переключении в Rage сила явно восстанавливается до Skill Level 20.

Arrow Color — общий цвет стрелок, подсветок, индикаторов шаха/угроз/мата и всех чамсов. Его изменение обновляет все цвета сразу, не включая функции. После этого отдельные цвета можно менять вручную.

## Firefox

Используется `@sandbox JavaScript` и `unsafeWindow`. Данные, возвращённые страницей, сериализуются в её контексте и копируются в обычные объекты userscript. Объект хода передаётся через `cloneInto` без передачи функций. Обработчики Worker регистрируются через `addEventListener`.

Это соответствует [документации Tampermonkey](https://www.tampermonkey.net/documentation.php?ext=hinc&q=sandbox) и [правилам передачи объектов Firefox](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Sharing_objects_with_page_scripts).

Полная FEN читается из действующей доски. Права рокировки и очередь не угадываются по изображению фигур. Внутренний интерфейс Chess.com может измениться; ошибка чтения позиции показывается в статусе.

## Производительность и данные

Без `crossOriginIsolated` / `SharedArrayBuffer` запускается полная однопоточная сборка. При доступной изоляции — полная многопоточная, автоматически до четырёх потоков с настройкой в пределах CPU. Hash ограничивается оценкой памяти устройства. Фактические значения показаны в меню.

Стили изолированы в Shadow DOM. SVG-подсветки не перехватывают клики. Расчёт ходов локальный, позиции не отправляются внешнему сервису анализа. Сеть нужна для файлов движка, аватара собственного профиля и включённого измерителя HTTP RTT.

Проверка настоящего Firefox/Tampermonkey — `node tests/firefox-native.mjs`. Для неё нужны geckodriver 0.37.1 в `.test-tools/geckodriver/` и официальный `tampermonkey-5.5.0.xpi` в `.test-tools/`. Она создаёт отдельный профиль и не использует ваш аккаунт. Инструменты и XPI в архив не включены.

Проверка только состояния меню при переходах на настоящем Chess.com: `node tests/firefox-native.mjs --navigation-only`.

Проверка фактической отрисовки масок фигур в Firefox: `node tests/firefox-native.mjs --visuals-only`. Сравниваются пиксели доски с включёнными и выключенными чамсами.

Проверка профиля и публичного аватара в Firefox/Tampermonkey: `node tests/firefox-native.mjs --identity-only`. В отдельном гостевом профиле создаётся тестовый элемент собственной навигации, затем загружается настоящий публичный аватар. Вход в аккаунт пользователя не требуется.

Проверка ручного включения в Firefox/Tampermonkey без сетевой загрузки движка: `node tests/firefox-native.mjs --session-only`. В гостевой партии с ботом анализ выключен; проверяются начальная пауза, сохранение вручную включённых режимов при обычных ходах и выключение после перезагрузки.

Проверка нового оформления в настоящем Firefox/Tampermonkey: `node tests/firefox-native.mjs --fatachessty-only`. Проверяются размеры, шрифты, полное название, колонки, переключатели, материал, редактор цвета, тулбар и перезагрузка; онлайн-ходы не выполняются.

`dist/ChessWare.user.js` — основной файл. `dist/chess-skeet.user.js` содержит тот же код для совместимости старой ссылки; устанавливать обе копии не нужно.
